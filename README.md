# 🎮 Tic Tac Toe Game – C++

A simple and interactive **Tic Tac Toe (X & O)** game built using **C++**, designed for two players in a terminal/console environment. This project demonstrates fundamental programming concepts such as loops, arrays, conditions, and basic game logic.

---

## 📌 Features

- 🧠 Two-player turn-based gameplay
- 🧾 Clear board UI using a 3x3 grid
- ⚠️ Input validation to avoid overwriting cells
- 🏆 Win and draw detection logic
- 🔄 Option to restart after game over

---

## 🛠 Tech Stack

- **Language:**  
  C++

- **Compiler:**  
  g++ or any C++ compatible compiler

- **Environment:**  
  Windows/Linux/Mac (runs in terminal or command prompt)
